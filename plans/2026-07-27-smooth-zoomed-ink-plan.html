Zenno implementation plan · 27 July 2026

Smooth ink that stays smooth when zoomed

Replace the visibly faceted edge construction with continuous quadratic curves while preserving every stored point, pressure value, brush width, and existing note.

Scope: canvas ink rendering Data migration: none Primary risk: geometry regression Target: Android ARM64

Diagnosis

Zenno already stores strokes as vector centerline samples and rebuilds higher-detail geometry at large zoom levels. The remaining roughness is in stroke_builder.dart: the outline points returned by perfect_freehand are joined with Path.lineTo. Those straight joins form a polygon. At normal size the facets are hard to notice; zoom magnifies them.

Current edge: straight joins

Every outline sample becomes a hard corner.

Planned edge: curved joins

Outline samples guide a continuous quadratic path.

Root-cause boundary: this is a renderer change, not an input-sampling or persistence change. Rewriting saved strokes would add data risk without fixing the polygonal path construction.

Implementation

1 · Generate Keep the existing pressure-aware and high-zoom outline point generation.
2 · Curve Join adjacent outline points through quadratic midpoint curves.
3 · Cache Continue caching the finished vector path by stroke revision and zoom bucket.
4 · Render Use the same path builder for live and committed ink.

Production change

Update only buildStrokeOutline so callers inherit the smoother geometry without duplicated logic or new settings.

Regression coverage

Add a focused geometry test proving the outline contains continuously changing curve tangents rather than only polygon segment directions.

Compatibility

Leave stroke IDs, point arrays, pressure, tilt, timing, tool, width, serialization, database tables, and import/export formats untouched.

Performance

Reuse the existing live-prefix, committed-path, and zoom-bucket caches. The change affects path commands, not the number of saved samples.

Verification and acceptance

  1. Run the focused stroke-builder, live-stroke, and element-painter tests.
  2. Run the complete Flutter test suite, static analysis, and git diff --check.
  3. Confirm old strokes load without migration and use the improved renderer.
  4. Build zenno.apk for android-arm64.

Visual acceptance

Pen, pencil, marker, highlighter, and airbrush outlines remain continuously smooth when zoomed beyond 4×, without sharp facets appearing between outline samples.

Integrity acceptance

No schema, codec, repository, import, export, or saved stroke payload changes. Existing notes are rendered, never rewritten.

Deliberate non-goals

  • No new brush controls or smoothing preference.
  • No destructive resampling of stored strokes.
  • No database migration or document-format version change.
  • No unrelated canvas, toolbar, or visual styling changes.
This plan is tied to the implementation branch fix/smooth-zoomed-ink and the current staging canvas pipeline.
